# Override Practice Arena

A playable 2D strategy simulator for the VEX V5RC 2026-27 game **Override**, with AI opponents for strategy practice.

**Play it here:** https://tropicmango.github.io/override-practice-arena/

## Controls

- **W/S** drive forward/back, **A/D** (or arrow keys) turn
- **E** hold to intake a pin or cup
- **Q** deposit (back up to a goal — the rear hatch must be inside the drop ring)
- **F/V** flip pin/cup, **T** work the toggle, **X** descore own goal
- **1-5** match load (in a LOAD zone), **P** physics on/off, **Space** pause

## Modes

Practice (1v2 with an AI teammate), Versus (1v1), Demo (2v2 watch-only), Solo Skills. Bots have pickable strategies (stacker, toggle rusher, defender, balanced) plus a difficulty slider.

No install needed — just open the page and play.
